# Security Policy

This project follows the [Apache Casbin security policy](https://github.com/apache/casbin/blob/master/SECURITY.md), which describes how to report security issues and what is not treated as a vulnerability.

Please report security issues privately to security@apache.org. Do not open public GitHub issues, pull requests or discussions for security issues.
